**Backend**

`Java 21` `Spring Boot` `Spring Security` `PostgreSQL` `Redis`

**Frontend**

`Next.js` `TypeScript`

**Infrastructure**

`Docker` `AWS EC2` `Nginx` `Cloudflare R2` `GitHub Actions`

- 👥 Buyer / Seller / Admin RBAC
